Sources can include a website sitemap, individual pages, Q&A pairs, topic text and supported files. The team configures the assistant's scope, greeting, voice, colors, logo and conversation starters to suit the site. Adding it to a website uses an embed script; the web team can add it to a supported platform such as WordPress or Shopify. No complete website rebuild is required.
Setup testing covers realistic first questions, changed constraints and follow-ups at desktop and phone widths. A branded widget must stay readable and usable on a small screen; this is part of tuning the actual website experience, not just checking a single answer.
Setup is collaborative: select sources and goals, set boundaries and styling, test typical and difficult questions, add the widget, then tune it from actual conversations. Do not promise an exact launch time without checking the site and scope. Content that is not publicly on the website can be supplied as approved chatbot guidance; that guidance can appear in visitor answers and is not secret storage.
